# 🌱 Automatic-Irrigation-system-using-IC-555-AND-LM741
Originally developed in 2021 as part of a Analog Electronics Course; this repository contains the finalized and cleaned version for public release.
## Overview
This project implements a fully automatic plant irrigation system capable of regulating water levels in supply tanks and maintaining optimal soil moisture. The circuit uses LM741 op-amp and IC 555 timer, designed as part of the Analog Electronics course to provide hands-on understanding of analog components and system design.
